THILINI KARUNASENA — ACADEMIC WEBSITE

FILES
-----
index.html  : Main website
style.css   : Website design and mobile styling
script.js   : Mobile navigation and automatic copyright year

HOW TO OPEN
-----------
Double-click index.html to preview the website in your browser.

BEFORE PUBLISHING
-----------------
1. Replace the email placeholder in index.html.
2. Add your LinkedIn and Google Scholar links.
3. Add a professional photograph.
4. Put your CV in this folder and name it:
   Thilini_Karunasena_CV.pdf
5. Replace the sample research/publication entries with your final citations.

FREE PUBLISHING OPTION — GITHUB PAGES
--------------------------------------
1. Create a GitHub account at github.com if you do not already have one.
2. Create a new public repository, for example: thilini-karunasena.github.io
3. Upload index.html, style.css, script.js, your photo, and your CV.
4. In repository Settings > Pages, select "Deploy from a branch".
5. Select the main branch and root folder.
6. GitHub will provide your public website address.

You can also connect a custom domain later.
